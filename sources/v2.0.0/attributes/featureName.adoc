// tag::featureName[]

.feature Name의 정의
* S-101 에서 복합 속성 span:A[feature name]과 그 하위 속성은 객체의 이름을 입력하는데 사용됨
* span:A[feature name]은 S-57 의 속성 span:A[OBJNAM]과 span:A[NOBJNM]과 대응됨
* span:A[feature name]은 하위 속성으로 span:A[language], span:A[name], span:A[name usage]를 가짐

//
.Multiplicity
* span:A[feature name]은 다중 속성 값을 지원하므로, 객체의 이름을 여러 언어로 입력할 수 있음
* 실세계에서 객체의 이름은 고유하므로, 데이터셋에는 각 언어별로 번역된 이름을 하나씩만 입력해야 함
** 예를 들어, 영어 이름이나 한글 이름을 중복 입력해서는 안 됨

.다중 입력 오류 예시

|    span:E[language]||(S)TE|1,1| eng
|    span:E[name]|OBJNAM/NOBJNM|(S)TE|1,1| Gumeongseom
|    name usage||(S)EN|0,1| 1 : default name display

|    span:E[language]||(S)TE|1,1| eng

.Sub Attributes
* span:A[language]
** 하위 속성 span:A[language]는 필수 속성으로, span:A[name]에 입력된 이름의 언어를 ISO 639-2/T 3글자 언어 코드(예: eng, kor)로 지정함
** 항해자가 ECDIS 화면에 표시할 언어를 선택하면 해당 언어로 이름이 표시됨

* span:A[name]
** 하위 속성 span:A[name]은 필수 속성으로, 입력된 이름은 항해자가 선택한 언어(span:A[language]에 지정된 언어 코드)에 따라 ECDIS 화면에 표시됨
** 이름을 입력할 때 영어 이름(eng)은 반드시 첫 번째로 입력해야 하며, 영어 이름 없이 한글 이름(kor)만 입력할 수 없음

* span:A[name usage]
** 하위 속성 span:A[name usage]는 다음 두 가지 값 중 하나를 가짐: 1(default name display), 2(alternate name display). 
** span:A[name usage] 값이 1이면 기본 언어(eng)로 이름이 표시되고, 값이 2이면 대체 언어(kor)로 이름이 표시됨
** span:A[name usage]를 입력하지 않으면 span:A[name]에 값이 있어도 화면에 표시되지 않으며, 항해자는 객체를 선택해 'Pick Report'로만 정보를 확인할 수 있음

.Encoding Guidance

* 해도의 영문 표기는 문화체육관광부고시 제2024-27호 「국어의 로마자 표기법」에 따라 표준 발음으로 로마자를 사용함
