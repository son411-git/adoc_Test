[[SourceIndication]]

= 자료 출처의 입력

. span:A[SORIND], span:A[SORDAT]
+
* S-101 Ed 2.0.0에서는 span:A[SORIND], span:A[SORDAT]에 완전히 대응되는 속성은 없음
* 하지만, 신규 HPD Source Profile에 span:A[SORIND], span:A[SORDAT]를 입력할 수 있도록 해서, (역변환을 통한) S-57 전자해도 제작 시 활용할 수 있도록 함
* Source Profile이기 때문에 S-101 Product DB에서는 관련 속성을 볼 수 없음
* S-57 Product DB에는 span:A[SORIND]는 span:A[SORIND]로, span:A[SORDAT]는 span:A[SORDAT]로 변환없이 그대로 동기화 됨
