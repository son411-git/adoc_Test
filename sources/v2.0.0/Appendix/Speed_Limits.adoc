[[Speed_Limits]]

= 속력 제한 구역의 입력

**속력 제한** :: 모든 선박 또는 특정 선박 등급에 대해 속력 제한이 설정된 경우, span:F[Restricted Area]를 사용하거나 span:A[restriction]을 가진 <<restriction_related_feature_list,관련 객체>>를 사용하며, span:A[restriction] = 27 span:D[speed restricted]로 입력해야 함

* 예 : 속력제한구역을 위해 입력하는 span:F[Restricted Area]와 span:F[PrecautionaryArea]이 중첩된다면 span:F[PrecautionaryArea]에 span:A[restriction] = 27 span:D[speed restricted]를 입력하고 span:A[vessel speed limit]을 사용하여 속력 제한에 관한 하위 속성을 입력할 수 있음

//
**항주파 제한** :: 항만 내에서 선박이 항해하면서 생기는 파도(항주파, wake)으로 인한 피해를 줄이기 위해 항주파 제한이 설정됨. 이는 span:F[Restricted Area]의 span:A[category of restricted area] = 24 span:D[no wake area ]또는  <<restriction_related_feature_list,관련 객체>>의 span:A[restriction] = 13 span:D[no wake]로 지정됨

//
* 선박 길이, 흘수, 또는 화물에 따라 달라지는 속력 제한과 같은 자세한 정보는 필요 시 span:A[information] 또는 span:A[pictorial representation]을 사용하여 입력할 수 있음
** 예: 항해용 간행물에 포함된 속력 제한 표를 그래픽으로 재현

//
* 항주파 또는 속력 제한이 있는 span:F[Restricted Area]를 표시하는 항로표지를 입력해야 하는 경우, span:F[Special Purpose/General Beacon] 또는 span:F[Special Purpose/General Buoy]를 사용해야 하며, +
span:A[category of special purpose mark] = 24 span:D[reduced wake mark] / 25 span:D[speed limit mark]를 입력하고, 속력 제한과 측정 단위는 복합 속성 span:A[information/text]를 사용하여 입력해야 함 (예: "speed limit is 6 knots")

//
* 제한 속력, 속력의 단위, 대상 선박 등급은 복합 속성 span:A[vessel speed limit]의 하위 속성 span:A[speed limit], span:A[speed units], span:A[vessel class]를 사용

**span:A[speed limit]** :: 
제한 속력을 나타내며, 0 ~ 35 사이의 실수를 소수점 첫째자리까지 필수로 입력
**span:A[speed units]** :: 
속력의 단위를 나타내며, **km/h**, **mph**, **knots** 중 하나를 필수로 입력
**span:A[vessel class]** :: 
선박 등급을 나타내며, 선박의 종류를 입력할 때 사용. 선택 사항으로, 최대 50글자까지 입력 가능

//
* vessel class 입력 시 주의사항
** 별도의 조건 없이 모든 선박을 대상으로 하는 경우에는 span:A[vessel class]를 입력하지 않음 _(Undefined)_
** span:A[vessel class]를 입력할 때 50글자를 넘어서는 안 됨
** span:A[vessel class]를 이용하여 선박의 종류를 입력할 때 아래 예시, 약어표를 참고하여 기술
*** 일반적으로 별도의 명시 없이 _(n)_톤 이상, 이하의 선박을 지칭하는 경우 총 톤수(GT)를 의미함
*** ~톤 이상을 나타낼 때는 over, ~톤 이하를 나타낼 때는 under를 사용
*** ~톤 초과를 나타낼 때는 more than, ~톤 미만을 나타낼 때는 less than을 사용

//
* 예시
** 총 톤수 500톤 미만 여객선 => Passenger ships less than 500 GT
** 1,000톤 이상의 선박 => All Ships over 1,000 GT
** 위험물 문반선 => Hazardous cargo arrier
** 그 외 모든 선박 (명시된 조건이 있고, 그 외에 나머지를 의미할 때에만 사용)=> All other vessels + 
   ( 이 때, 그 외 모든 선박에 대한 vessel speed limit는 맨 마지막 값으로 입력한다. )
