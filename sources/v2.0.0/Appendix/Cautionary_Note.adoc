5+| ※ 비고 : +
출입 금지(entry prohibited): 항해 및/또는 정박이 금지된 구역. +
출입 제한(entry restricted): 관련 당국이 지정한 특정 구역으로 특정 조건에 따라 항해가 제한되는 구역. +
