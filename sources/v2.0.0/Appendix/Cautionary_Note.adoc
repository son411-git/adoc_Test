[[Cautionary_Note]]

= 주의기사 (국문/영문) 입력 방법

* span:F[Caution Area], span:F[Information Area], span:F[Nautical Information] 또는 해당 객체의 span:A[information] 등 관련 속성에 입력되는 주의기사의 입력 방법을 정리

* 문자열을 입력할 경우, 속성마다 문자 유형과 길이 제한이 다르며 **시작/끝 공백** 및 **줄바꿈**은 절대 포함 불가합니다.

* span:E[주의] 아래 내용은 KHOA INT2 (2025.06.24) span:D[INT2_2_Ed2025_KHOA_250624], 외부참조파일(*.txt)을 기준으로 작성되었으며, 내용이 서로 다를 경우 최신의 KHOA INT2에 작성된 내용을 우선으로 하였음
