// tag::UnsurveyedArea[]
===== Remark
* span:F[Unsurveyed Area]는 Skin of the Earth에 포함되는 객체이므로, Skin of the Earth에 포함되는 다른 객체와 중첩되어서는 안 됨
* span:F[Unsurveyed Area]에 수심 및 측량데이터가 없는 경우 span:F[Quality of Bathymetric Data]와 중첩 불필요
* span:F[Unsurveyed Area]는 객체 외에 별도로 입력되는 속성이 없음
* 공사구역의 미측은 span:F[Information Area]와 함께 입력
* span:A[information]에는 미측구역, 공사중 등의 일반적인 정보 외의 추가정보만 입력 + 
  (미측구역 정보는 span:F[Unsurveyed area] 자체의 의미이므로 삭제하고, 공사중 정보는 span:F[Information Area]에 입력)

* 현재 국내 전자해도에는 소축척의 백판구역(대축척참조)에 span:F[Unsurveyed Area]를 사용(입력예시 참조)
