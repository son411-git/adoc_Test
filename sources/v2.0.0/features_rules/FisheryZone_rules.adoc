===== Remark

* span:F[Fishery Zone]는 연안 국가가 영해 안팎에서 독점적으로 어업을 규제할 수 있다고 선언한 구역임
* 해당 구역의 특정 부분에서 타국의 어업을 허용한 경우, 전체 어업 구역과 특별 양허 권한 구역을 모두 입력하는 것이 유용할 수 있음
//
* 어업자원보호법 제1조(관할수역) 참고
