===== Remark

* 암초는 <<UWTROC_T1,Underwater Awash Rock 입력 기준>>과 같이 기본수준면 기준으로 잠기는 또는 닿는 정도에 따라 간출암, 세암, 암암으로 구분하여 입력

* *산호초의 경우* span:A[nature of surface] = 14 span:D[coral]로 입력 +
  그렇지 않은 경우 span:A[nature of surface]는 입력하지 않음 _(undefined)_

* 필수속성인 span:A[value of sounding] 은 암초의 확인된 수심을 입력
