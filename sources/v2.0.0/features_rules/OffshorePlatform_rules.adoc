===== Remark

* 해상 플랫폼을 입력할 때에는 반드시 span:F[Offshore Platform]를 사용
** span:A[height]는 고정식 플랫폼에만 사용해야 하며, 참조하는 수직 기준면에 대해서 입력
** span:A[vertical length]는 부유식 플랫폼에만 사용해야 하며, 해수면을 기준으로 입력

//
* 해체된 플랫폼의 잔해 등을 입력할 때에는 보통 span:F[Foul Ground]를 사용
** 단, 해저에서 충분히 돌출되어 항해에 장애가 될 경우에는 span:F[Obstruction]을 사용
//
* 플랫폼에는 등화, 무신호, 헬리콥터 착륙장 등 장비 역할의 객체들이 설치될 수 있으며, 이 경우 span:F[Offshore Platform]과 span:R[Structure/Equipment] 관계를 설정해야 함
** (주로 석유나 가스 시추 시설에서)연소탑이 있는 경우, span:A[flare stack]으로 유/무를 입력
//
* 해양 기상탑과 같은 관측을 위한 구조물은 span:F[Offshore Platform]을 사용하여 입력하고, span:A[category of offshore platform] = 3 span:D[observation/research platform]을 입력

* 대축척에서는 Surface 형태로 입력하고, 소축척에서는 Point 형태로 일반화 할 수 있음
