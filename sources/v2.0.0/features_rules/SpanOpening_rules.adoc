// tag::SpanOpening[]
===== Remark

* **항해가 가능한 지역**의 개방형 교량의 개방부는 span:F[Span Opening]으로 입력
** 항행이 불가능한 지역의 경우는 span:F[Bridge]로 입력

* span:F[Span Opening]는 반드시 span:R[Bridge Aggregation] 관계에 포함되어야 함 <<BRIDGE_AGGR,※참조>>
** 이 때, span:R[Bridge Aggregation]에 포함된 span:F[Bridge]의 span:A[opening bridge]는 true로 설정해야 하고, span:A[category of opening bridge]를 필수로 입력해야 함

* 통항이 가능한 수직높이는 닫혀 있을 때와, 열려 있을 때를 구분하여 입력해야 함
** 닫혀 있을 때는 span:F[Span Opening]의 span:A[vertical clearance closed] 속성에 입력
** 열려 있을 때는 span:F[Span Opening]의 span:A[vertical clearance open] 속성에 입력
*** 만약, 열려 있을 때 수직높이가 무제한인 경우, span:A[vertical clearance unlimited] 속성을 true로 설정하고, span:A[vertical clearance value] 속성은 입력하지 않음
include::common/phrase.adoc[tag=verticalDatum_for_clearance]
