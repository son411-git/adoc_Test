// tag::Helipad[]
===== Remark

* 헬기장(Heliport)은 span:F[Airport/Airfield]로 입력하며, span:F[Airport/Airfield]로 입력된 경우, 개별 span:F[Helipad]를 입력할 필요 없음

헬기장(Heliport) :: 헬리콥터를 위한 공항 또는 비행장으로, 하나 이상의 헬리패드와 추가 시설(연료 공급, 격납고, 터미널, 관제 시설 등)을 포함하는 더 큰 구역

헬기착륙장(Helipad) :: 헬리콥터가 이착륙할 수 있는 특정한 평평한 구역으로, 주로 단일 착륙 지점을 의미합니다. 병원, 해상 플랫폼, 건물 옥상 등에 설치

* 수상에서 헬리콥터가 착륙할 수 있는 구역을 입력하는 경우 span:F[Seaplane Landing Area]를 사용

* span:F[Helipad]가 span:F[Offshore Platform]의 일부로 입력되는 경우 span:R[Structure/Equipment] 관계 설정
