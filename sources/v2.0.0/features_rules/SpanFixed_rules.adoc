===== Remark

* **항해가 가능한 지역**의 고정형 교량의 경간은 span:F[Span Fixed]으로 입력
** 항행이 불가능한 지역의 경우는 span:F[Bridge]로 입력

* 경간을 개별로 표시할 수 없는 경우, 전체 교량을 하나의 span:F[Span Fixed]로 입력하고 가장 중요한 경간을 기준으로 속성을 입력

* span:F[Span Fixed]는 반드시 span:R[Bridge Aggregation] 관계에 포함되어야 함 <<BRIDGE_AGGR,※참조>>

* 통항이 가능한 수직높이는 span:A[vertical clearance fixed]로 입력
include::common/phrase.adoc[tag=verticalDatum_for_clearance]
