// tag::LandRegion[]
===== Remark

* 육지의 자연 경관이나 지리적 이름을 입력할 때는 span:F[Land Region]으로 입력
* 바다의 경우 span:F[Sea Area/Named Water Area]를 사용하여 입력
* 모래 언덕, 언덕, 절벽 등은 필요에 따라 span:F[Sloping Ground] 또는 span:F[Slope Topline]를 사용하여 입력
* span:F[Land Region][S]은 가능하면 다른 객체(예: span:F[Coastline])가 사용하는 가장자리(edge)로 경계를 설정하는 것을 권장함. 
* span:A[category of land region] 속성에 특정 값이 없는 경우, 곶·갑(Cape), 끝·점(Point), 반도(Peninsula) 등의 일반 용어를 span:A[feature name] 포함할 수 있음. 단, 해당 이름이 하위 span:F[Land Area]에 이미 채워져 있는 경우 span:F[Land Region]은 입력하지 않아야 함

//
* 해안선 뒤쪽의 습지를 입력하는 경우, span:A[category of land region] = (2 : marsh)로 입력
* 습지 지역의 바다 쪽 경계가 해안선과 일치하는 경우, 해당 경계는 span:F[coastline]에 span:A[category of coastline] = (8 :marshy shore)로 입력

//
* 염전을 입력해야 하는 경우, span:A[category of land region = (15 : salt pan)로 입력해야함
** 염전은 span:F[Land Area] 위에 입력해야 함
** 염전의 바다 쪽 경계가 해안선과 일치하는 경우, 해당 경계는 Coastline 객체를 사용하여 인코딩해야 하며, 속성 span:F[coastline]에 span:A[category of coastline] = (2 : flat coast)로 입력

//
