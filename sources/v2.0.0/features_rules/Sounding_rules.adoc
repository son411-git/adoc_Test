===== Remark

* 수심은 X,Y,Z 좌표를 갖는 3차원 Point의 집합
** 단일 포인트를 표현하는 경우도 있지만, 일반적으로는 여러 개의 Point를 그룹화하여 표현

* span:F[Sounding] 그룹화 시 주의사항
** 하나의 span:F[Sounding](그룹)이 서로 다른 span:F[Sounding Datum]에 걸쳐 있지 않도록 주의해야 함
** 업데이트에 의해 추가되는 수심은 이미 존재하는 span:F[Sounding] 그룹에 포함되지 않도록 주의해야 함 +
   ( 업데이트 시에는 그룹화를 해제하고 다시 그룹화하는 작업을 하지 않아야 함 )
** 개정할 때에는 기존에 만들어진 그룹을 모두 해제하고, 다시 그룹화해야 함

* 수심은 종이해도나 전자해도 상 표출을 위해 span:F[Spatial Quality]의 span:A[quality of horizontal measurement]나, span:A[quality of vertical measurement]을 입력해야 함 
** 실제 위치의 수심, 간출 수심등의 경우 span:A[quality of vertical measurement]는 1span:D[depth known] 또는 _(Undefined)_ 두 가지 모두 허용하지만, +
   가급적 __(Undefined)__로 입력할 것을 권장
