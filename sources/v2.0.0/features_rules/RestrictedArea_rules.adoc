===== Remark

* 제한구역은 span:F[Restricted Area]을 사용하여 입력하고, 제한사항은 span:A[restriction]을 이용해 표현
** 일반적으로 span:A[restriction]를 이용해 제한 사항을 표현하지만, 속성의 값으로 표현하기 어려운 복잡한 제한에 대해서는 span:A[information]을 이용해서 기술 ( 이 때, restriction은 _(Unknown)_ 으로 입력 )
** 만일, 제한구역과 동일한 영역을 가진 다른 객체가 span:A[restriction]을 갖는 경우, 해당 객체에 제한사항을 표기하고, span:F[Restricted Area]는 생략 +
  ( 예를 들어 통항 분리제도의 주의 해역에서 속력이 제한된다면, Precautionary Area의 restriction으로 표현하고 Restricted Area는 추가로 입력하지 않음 )
