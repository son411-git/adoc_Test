===== Remark

* 통항분리제도 중 회전 교차 구역을 의미

** span:F[Traffic Separation Scheme Roundabout]은 통항분리제도를 구성하는 요소 중 다음 요소들과 중첩되어서는 안됨 span:D[그림의 파란색 선 부분만 입력]
