===== Remark

* span:F[Radio Station] 자체가 건물이나 구조물을 의미하지는 않으므로, 필요한 경우 span:F[Building] 등의 객체로 건물이나 구조물을 입력
* 무선국의 종류에 따라 span:F[Radio Station]의 속성 span:A[category of radio station]을 입력
** DGNSS 기지국을 입력할 때는 span:A[category of radio station] = 10 span:D[differential GNSS]으로 입력
** Loran-C는 해도에 사용하지 않으나, 꼭 필요한 경우 span:A[category of radio station] = 9 span:D[loran C]로 입력

**주의**:: AIS는 span:F[Physical AIS Aid to Navigation] 또는 span:F[Virtual AIS Aid to Navigation]으로 입력해야 함

//REVIEW: Frequency Pair 속성에 관한 지침을 추가할 필요 있음

* 항로표지 정보의 입력은 <<ListOfLights,링크>>를 참고
