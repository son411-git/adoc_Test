// tag::FortifiedStructure[]
===== Remark

* 일부 해안선에는 방어 구조물이 있으며, 종종 사용되지 않거나 노후되어 방어 외 목적으로 쓰임
* 주요 성곽부터 소규모 감시 초소까지 다양하며, 곶이나 해안선의 항해목표물로 사용될 수 있음
* 국내 지침 : 군사 시설은 보안상 국내 해도에는 입력하지 않음 (해도제작 업무편람)
