===== Remark
- 양방향 항로부는 일반적으로 양방향이지만, <그림 A>와 같이 일방통항으로 제한할 수 있으며 [Traffic flow]에 지정
- <그림 B>와 같이 span:A[Orientation value] 값에 따라 span:F[Two-way route part] 피처를 개별 생성하고 span:R[Two-way route Aggregation] 관계를 설정 +
  ※ Relation 페이지 참조
- span:R[Two-way route Aggregation]에 포함되는 모든 피처는 동일한 span:A[Scale minimum] 값을 가져야 함
- span:F[Two-way route part] 피처는 반드시 span:R[Two-way route Aggregation] 관계를 설정해야 하며 span:R[Two-way route Aggregation]의 속성에 항로의 명칭을 입력(<<TWRT_AGGR,※참고>>)
