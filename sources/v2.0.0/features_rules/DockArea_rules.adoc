// tag::DockArea[]
===== Remark

* span:F[Dock Area]는 항해가 불가능한 지역에만 입력해야하며 span:F[Land Area] 또는 span:F[Unsurveyed Area]로 덮여야 함
* span:F[Dock Area]의 경계는 별도로 입력하지 않아야하며, span:F[Gate]는 예외임
* span:F[Dock Area]의 입구 크기는 span:A[horizontal clearance fixed]에 입력
* 항해가 가능한 부분의 길이와 너비는 span:A[horizontal clearance length]와 span:A[horizontal clearance width]로 입력
* 알려진 span:F[Dock Area]의 이름은 span:A[feature name]에 입력

//
* 항해가 가능한 도크는 span:F[Depth Area], span:F[Dredge Area], span:F[Unsurveyed Area]를 사용해야하며, span:F[Dock Area]는 사용하지 않아야 함
* 경계는 span:F[Coastline], span:F[Shoreline Construction], span:F[Gate]으로 입력
* 알려진 span:F[Dock Area]의 이름은 span:F[Sea Area/Named Water Area]를 사용하여 입력해야 함

// 
* 습식 도크(비조수 도크)는 바깥 바다와 다른 수심 기준면(sounding datum)을 사용할 수 있으며 해당 영역에 span:F[Sounding Datum]을 span:A[vertical datum] = 24 span:d[local datum] 으로 입력
