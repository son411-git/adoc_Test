// tag::TrafficSeparationSchemeLanePart[]
===== Remark

* 통항분리제도에서 한쪽 방향으로 항행이 가능한 구역을 의미
** 합류구간(Junction)도 span:F[Traffic Separation Scheme Lane Part]으로 입력하지만, 이 때는 span:A[orientation value]를 입력하면 안 됨
*** 그외에는 span:A[orientation value]를 반드시 입력

//
** span:F[Traffic Separation Scheme Lane Part]은 통항분리제도를 구성하는 요소 중 다음 요소들과 중첩되어서는 안됨 span:D[그림의 파란색 선 부분만 입력]
*** span:F[Traffic Separation Scheme Crossing]
*** span:F[Traffic Separation Scheme Roundabout]
*** span:F[Separation Zone or Line] span:D[Surface 형태의 경우]

//
* span:F[Traffic Separation Scheme Lane Part]은 다른 구성요소와 함께 span:F[Traffic Separation Scheme]과 span:R[Traffic Separation Scheme Aggregation] 관계를 가져야 함 (<<TSS_AGGR,※참고>>)

//
* 통항구역에 관한 항행 제한사항이 있다면, span:A[restriction]을 이용하여 입력 할 수 있음
** 단, 중첩되는 span:F[Restricted Area]에 동일한 제한사항에 대해 입력되어 있다면, span:F[Traffic Separation Scheme Lane Part]에는 span:A[restriction]을 생략함

//REVIEW: 아래 내용 남아 있을 필요가 있는지?
// - 항로별 명칭이 별도로 있는 경우 #A "Information"으로 입력(ex. 입항항로) 하고, 전체 항로 명칭은 #F "Traffic Separation Scheme"에 입력 후 관계 설정 (항로명 필수 입력)

|Attribute |Acronym |Type |Mult. |Value

|restriction|RESTRN|EN|0,*| 1 span:D[anchorage prohibited]
|**information**|INFORM|C|0,*|  
|    span:E[language]||(S)TE|1,1| eng 
|    text|INFORM/NINFOM|(S)TE|0,1| Junction Area
|**information**|INFORM|C|0,*|  
|    span:E[language]||(S)TE|1,1| kor

|===
