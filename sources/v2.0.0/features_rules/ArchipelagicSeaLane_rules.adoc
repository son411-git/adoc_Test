===== Remark

* 군도수로항로는 span:F[Archipelagic Sea Lane]로 입력하고 이름은 span:A[feature name]으로 입력

//
* 객체 관계
** span:R[ASL aggregation]을 정의하기 위해 구성 객체를 span:F[Archipelagic Sea Lane]로 객체 관계를 맺어야함 (<<ASL_AGGR,※참고>>)
** span:F[Archipelagic Sea Lane]의 공간적 범위는 구성 객체들의 전체 범위를 포함해야함
** span:R[ASL aggregation]는 최소한 하나의 구성 객체를 반드시 포함해야함
** span:R[ASL aggregation]의 구성 객체는 같은 span:A[scale minimum] 값을 가져야 함

//
include::common/information.adoc[]
