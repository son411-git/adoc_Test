// tag::Pile[]
===== Remark

* 일반적인 말뚝, 기둥은 span:F[Pile]로 입력
** 말뚝이나 기둥이 연속적으로 설치된 경우, +
   span:F[Pile][C] - span:A[category of pile] = 5 span:D[piling]로 입력하거나, +
   span:F[Pile][S] - span:A[category of pile] = 6 span:D[area of piles]로 입력할 수 있음
** 소축척에서는 span:F[Pile][P]로 일반화 할 수 있음

//
* 항행에 위험한 말뚝,기둥은 span:F[Pile]로 입력해서는 안되며, span:F[Obstruction]로 입력하고, span:A[category of obstruction] = 1 span:D[snag/stump]로 입력해야 함

//
* 항로표지 역할을 하는 말뚝, 기둥은 span:F[Pile]로 입력해서는 안되며, 목적에 맞는 **Beacon** 객체로 입력해야 함
** 이 때, span:A[beacon shape]는 1 span:D[stake, pole, perch, post]로 입력

//REVIEW:: 교량등의 파일은 Bridge에 직접 연결, 기상탑은 Pile이 아니라 Beacon이던 Offshore 던 제외하고 나면, Pile에 입력할 예시가 없음
