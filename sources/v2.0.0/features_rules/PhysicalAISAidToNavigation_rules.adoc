===== Remark

**span:E[주의]**:: AIS에 대해서는 더 이상입력하지 않음

* 물리적 AIS를 인코딩해야 하는 경우, 반드시 span:F[Physical AIS Aid to Navigation]을 사용 (span:F[Virtual AIS Aid to Navigation]과 구분)

* AIS 신호가 다른 위치에서 송신되는 경우(Sythnetic V-AIS), 실제 신호를 보내는 기지국은 span:F[Radio Station] 피처로 입력하며, span:A[category of radio station] = 20 span:D[AIS base station]으로 입력
//REVIEW:: 기존 내용이 이상함; 항로표지 없이 단독으로 입력된 경우에 관한 설명

//
* MMSI(Maritime Mobile Service Identity; 해상이동업무식별번호)를 알 수 있는 경우, span:A[MMSI Code]에 입력 (9자리 숫자)
** [참고] - 일반적으로 MMSI 코드는 아래와 같은 형식으로 부여할 것을 권고하고 있음; Recommendation ITU-R M.585 (Section 4) +
*** Physical AIS AtoN : 99MID1XXX
*** Virtual AIS AtoN : 99MID6XXX
//
