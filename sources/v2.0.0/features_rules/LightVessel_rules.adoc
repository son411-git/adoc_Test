===== Remark

* span:F[Light Vessel]은 일반적으로 광달거리가 10해리 이상으로 **주요 부유 등화(Major floating lights)**로 분류됨. 
** 예외적으로, 고립된 위치와 같은 특별한 상황에서는 더 낮은 범위의 부유 등화도 **주요 부유 등화(Major floating lights)**로 지정될 수 있음.
