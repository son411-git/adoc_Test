// tag::DistanceMark[]
===== Remark
* 항로를 따라 해리, 킬로미터 또는 기타 측정 단위로 거리를 표시하는 표지는 대축척 전자해도에서 유용한 것으로 간주됨
* 거리가 측정된 기준점은 span:A[reference location]을 사용하여 표시
* span:A[distance mark visible]은 필수 속성이며 (true)로 입력된 경우, +
표지를 지지하는 구조물 역할의 객체와 연관되어 span:R[Structure/Equipment]를 맺을 수 있음
include::common/NotUsedFeature.adoc[]
