// tag::Gate[]
===== Remark

* span:F[Gate]가 개방된 위치에서 상단 구조물이 없어 수직 간격이 무제한인 경우, span:A[vertical clearance open/vertical clearance unlimited] = (true)로 설정
* 반대로 span:F[Gate]가 개방된 위치에서 상단 구조물이 있어 수직 간격에 제한이 있는 경우, span:A[vertical clearance open]의 하위 속성 span:A[vertical clearance value]는 필수로 입력하고, span:A[vertical clearance unlimited] = (false) 로 입력
* span:F[Gate] 는 span:F[Depth Area], span:F[Dredged Area], span:F[Unsurveyed Area] 또는 span:F[Land Area]로 덮여 있어야 함
* 알려진 경우, span:A[depth range minimum value]는 문턱(gate sill) 위의 최소 깊이를 입력하는데 사용
* span:A[vertical datum] = ( 13 : low water )은 내륙 수로에만 적용되며, 조위가 적용되는 수역에서 수직 기준면을 나타내는 데 사용되어서는 안됨
