// tag::AdministrationArea[]
===== Remark

* 국가가 정한 영토나 수역의 관할 구역을 구분하기 위해서 span:F[Administration Area]을 입력
* 일반적으로 소축척해도에서 국경의 입력
* span:A[nationality]는 ISO 3166 표준에 따라 2자리의 대문자 영문 코드로 입력

[inclue]
===== Example

.Administration Area의 인코딩 예시
[cols="30,25,10,10,25", options="header"]
|===
|Attribute |Acronym |Type |Mult. |Value

|span:E[jurisdiction]|JRSDTN|EN|1,1| 1: international
|nationality|NATION|TE|0,*| KR
|**feature name**||C|0,*| 
|    span:E[language]||(S)TE|1,1| eng
|    span:E[name]|OBJNAM/NOBJNM|(S)TE|1,1| Republic of Korea
|    name usage||(S)EN|0,1|1 : default name display
|**feature name**||C|0,*| 
|    span:E[language]||(S)TE|1,1| kor
|    span:E[name]|OBJNAM/NOBJNM|(S)TE|1,1| 대한민국
|    name usage||(S)EN|0,1|2 : alternate name display
|===
