===== Remark

* span:F[Emergency Wreck Marking Buoy]는 선박 침몰 시 해당 침선에 대한 영구적인 해도 표기 방식이 확정되어 항행통보를 통해 공표되거나, 침선이 제거(인양)될 때까지 새로운 침선의 위치를 표시하는 데 사용됨

* 필수 속성 : IALA 해상 부표 시스템에 따라,
** 부표의 형상은 망대(pillar) 또는 원주(spar) 만 허용됨
** 도색는 파란색과 노란색의 세로 줄무늬로 구성됨
** (장착된 경우) 두표는 노란색 십자가
** (장착된 경우) 등화는 Al.Oc.BuY.3s 를 사용해야 함, (해도에 표기하지 않지만 광달거리는 IALA 규정에 의해 **4 해상마일(M)** 임)
** (장착된 경우) 레이콘은 모스 부호를 **D**로 사용해야 함
** 위 조건에 따른 속성의 조합은 아래 표를 참고하여 입력
