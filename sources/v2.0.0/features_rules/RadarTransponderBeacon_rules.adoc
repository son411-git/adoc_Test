====

명칭:: '등표'를 제외한 **신도타서**만 입력
부호:: **G**는 span:A[signal group]에 괄호로 묶어서 입력
주파수:: 주파수를 직접입력하지 않음; 단 band 별 span:A[wave length value]에 잘 맞는지 확인
전력:: 전력란의 사용 밴드 (X-Band, S-Band)를 확인 후 span:A[radar band]에 입력; 아래 W 값은 공중선 전력값을 의미하므로 입력하지 않음
측정구역:: span:A[value of maximum range]에 입력
참고:: 레이콘은 일반적으로 9300 ~ 9500 MHz인 X-Band , 2900 ~ 3100 MHz인 S-Band를 사용하므로, 아래 수식에 따라 파장을 계산할 수 있음
[latexmath]
++++
\lambda = \frac{c}{f}
++++
X-Band는 약 0.032 span:D[m], S-Band는 약 0.098 span:D[m]이므로 속성에서 요구하는 정밀도에 맞게 반올림하면 X-Band는 0.03 span:D[m], S-Band는 0.1 span:D[m]
