===== Remark

* span:A[surface characteristics]는 최소 하나 이상 입력해야 함
** 표층의 저질만 입력하는 경우 하위 속성인 span:A[underlying layer]를 생략할 수 있음
** 여러 층의 저질을 입력하는 경우 표층 - 0을 기준으로 1, 2, 3.. 과 같이 순차적으로 span:A[underlying layer] 값을 입력
** 하나의 층에 저질의 혼합되어 있는 경우, 주된 성분을 먼저 입력하고, 각 저질의 span:A[underlying layer]는 동일한 값으로 표현
** 저질의 특성을 추가로 기술하기 위한 span:A[nature of surface - qualifying Terms]는 span:A[nature of surface]에 따라 허용되는 값이 다름 + 
   ( <<SEABED_T1>>에 X 표시된 조합만 사용가능 함 )

//
* 조간대와 수중의 구별을 위해 span:A[water level effect]를 주변 span:F[Depth Area]에 맞게 입력
