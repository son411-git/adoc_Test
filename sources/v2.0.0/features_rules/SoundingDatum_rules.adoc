===== Remark

* 수심에 관한 수직기준면은 span:F[Sounding Datum]으로 기술 (S-57과 다르게 Dataset의 메타데이터가 아닌 메타 객체로, 인코딩)

* span:F[Sounding Datum]와 다른 메타 객체와의 관계
** span:F[Sounding Datum] 끼리는 서로 중첩되서는 안 됨
** 하나 이상의 span:F[Quality of Bathymetric Data]로 완전히 덮혀야 함 + 
   ( 측량연도 등의 정보가 다르더라도, 수심기준면이 동일한 경우에는 하나의 span:F[Sounding Datum]로 입력 )
** span:F[Vertical Datum of Data]와는 중첩되어도 무방함 (별개의 정보)

//REVIEW: 이런 주의사항들을 적어도 될지?
**span:E[주의]**:: 서로 다른 span:F[Sounding Datum]이 맞닿아 경계를 이루는 경우 다음에 주의해야 함
* span:F[Sounding](그룹), span:F[Depth Area], span:F[Depth Contour]는 서로 다른 span:F[Sounding Datum]에 걸쳐 있지 않도록 주의 +
** 이런 경우, span:F[Sounding](그룹), span:F[Depth Area], span:F[Depth Contour]는 분할해서 어느 한쪽의 span:F[Sounding Datum]에만 속하도록 입력해야 함
* Point 유형의 경우, 경계에 걸쳐 있지 않도록 주의해야 함 +
** 특히 span:A[value of sounding]이나 span:A[water level effect] 속성을 가지는 경우, 적용되는 기준면이 어떤 쪽인지 구분할 수 없기 때문에, 경계에 걸쳐 있지 않도록 주의 +
   (예: Obstruction, Wreck, Underwater Awash Rock, Seabed Area 등)
