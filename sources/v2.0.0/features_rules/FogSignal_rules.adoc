===== Remark

* span:F[Fog Signal]는 안개, 눈, 노을, 호우, 연무 등에 의하여 시계가 불량할 때 소리로 선박에 그 위치를 알림
* span:F[Fog Signal]은 장치 자체가 아니라 방출되는 소리를 의미하며, 방출 위치가 보통 표지 또는 등화와 충분히 가까워 동일 위치로 간주함
* span:F[Fog Signal]은 신호 범위가 짧은 단거리 항로표지로써 주로 위험 경고로 사용되며, 위치 표지로는 신뢰성이 낮아 다른 항로표지에 비해 중요도가 떨어짐
* 전자 장비가 제한적이거나 작동하지 않는 선박의 안전 항행에 유용함

//
* span:F[Fog Signal]의 소리 방출 횟수(예: 폭음, 타격)와 주기가 알려진 경우 span:A[signal group], span:A[signal period],span:A[signal sequence]를 사용하여 입력해야 함

* 필요한 경우, 속성 span:A[signal frequency]는 헤르츠(Hz) 단위로 입력 (예 : 950 MHz → 950000000)

//
* span:F[Fog Signal]이 무선으로 활성화되는 경우, span:A[signal generation] = 5 span:d[radio activated]로 입력해야 함

* span:F[Fog Signal]이 관제소 호출로 활성화되는 경우, span:A[signal generation]은 6 span:d[call activated]로 입력해야 함

** 신호 활성화에 필요한 연락 정보를 입력하려면 span:F[Contact Details]를 사용해야 하며, span:F[Fog Signal]와 span:R[Additional Information]로 관계 맺어야 함

//
* 항로표지 정보의 입력은 <<ListOfLights,링크>>를 참고

//

* 속성 입력 방법
include::common/featureName_for_AtoN.adoc[]
** 종류는 Siren 이므로, span:A[category of fog signal] = 3 span:d[siren]을 입력
** 주기는 60s 이므로, span:A[signal period] = (60)을 입력
** 리듬은 취명과 정명이 각각 두 번씩 반복되므로, span:A[signal group] = ((2))을 입력
** 상태는
  - 취명(빛이나 신호가 발생하는 상태)은 span:A[signal status] = 1 span:d[lit/sound]로 입력
  - 정명(빛이나 신호가 멈춘 상태)은 span:A[signal status] = 2 span:d[eclipsed/silent]로 입력
  - span:A[signal status]는 신호 순서에 따라 입력
** 각 신호의 지속 시간은 span:A[signal duration]에 소수점 첫째 자리 초(sec) 단위로 순서대로 입력
