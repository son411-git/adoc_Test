실질적으로는 어떠한 정보도 제공 못하는 입력 방식이 필요한지?

계속해서 관측하는 것도 아니어서 station name, number가 있을리 없고

예시에는 tidal stream panel values를 억지로 넣어뒀지만, 실제론 입력 예가 없음
reference tide 및 tide type도 당연히 없고

"조류예보표를 참조할 것" 이라는 말 말고는 아무 의미가 없는데
조류예보표의 어디를 찾아보라는 설명도 없고

"조류예보표"라는 명칭의 항해용 간행물 따위는 없음

대체 어쩌란 말인가

이렇게 입력할 꺼면 그냥 다 빼는게 맞음
