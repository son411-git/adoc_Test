// tag::CoastGuardStation[]
===== Remark

* 해상 구조 조정 본부(MRCC), 해상 구조 하위 본부(MRSC)의 위치를 입력
** span:F[Contact Details], span:F[Service Hours] 를 사용해 선위통보 방법과 운영시간을 입력하고 span:R[Addtional Informaion] 관계를 맺어야 함
* 또한, 지속적으로 또는 특정 시간 당직으로 연안을 감시하는 해양경찰의 기지를 span:F[Coast Guard Station]로 입력
** 해양경찰의 일반적인 건물은 span:F[Building], span:F[Landmark] 등으로 입력

//
* 참고
** 해상구조조정본부 지정 및 운영 등에 관한 고시 (해양경찰청 제2021-7호)
** https://gisis.imo.org/Public/Default.aspx[IMO - Global Integrated Shipping Information System]
