// tag::LandArea[]
===== Remark

* 바다에 절대 덮이지 않는 육지는 span:F[Land Area]를 사용하여 입력
** 특히, span:F[Land Area][S]는 지구 표면(Skin of the Earth)의 일부임
<<SkinOfEarth,※참고>>
* 편집 축척에서 항해가 불가능한 span:F[Lake], span:F[River], span:F[Dock Area], span:F[Lock Basin], span:F[Canal]는 span:F[Land Area][S] 위에 입력해야 함

//
* 육지의 자연 경관을 설명해야 하는 경우, span:F[Land Region] 사용해야 함
* span:F[Land Area]는 일반적으로 면(surface) 형태이지만, 점(point) 유형(예: 작은 섬, 노출암) 또는 곡선(curve) 유형(예: 작은 섬, 연안 사주, 지협)일 수도 있음
* span:F[Land Area][P]는 면(surface) 형태의 span:F[Lake], span:F[River], span:F[Dock Area], span:F[Lock Basin], span:F[Canal]에 의해 덮이는 경우에 만,  span:F[Land Area][S] 위에 입력할 수 있음. 그 이외의 경우에는 span:F[Land Area][P]와 span:F[Land Area][S]를 중복하여 입력해서는 안 됨
* 국내 기준 : span:F[Land Area][C]는 입력하지 않음

//
* span:F[Land Area][S]의 경계는 다음 중 적어도 하나의 객체를 공유해야함

.Land Area[S]의 경계를 이루는 객체
[cols="10,50", options="header"]
|===
|Primitives |Feature

h| Curve
| span:F[Coastline],
span:F[Shoreline Construction],
span:F[Gate],
span:F[Dam]

h| Surface
|span:F[Data Coverage],
span:F[Dolphin],
span:F[Gate],
span:F[Dam],
span:F[River],
span:F[Tunnel],
span:F[Dry Dock],
span:F[Canal],
span:F[Lake],
span:F[Lock Basin],
span:F[Dock Area],
span:F[Land Area],

.2+h|Surface +
(with water level effect)
|span:F[Causeway], span:F[Shoreline Construction], span:F[Wreck], span:F[Obstruction], span:F[Pylon/Bridge Support]
|Attributes: span:A[water level effect] = (1 : partly submerged at high water, 2 : always dry 또는 6 : subject to inundation or flooding)
|===

//
* 노출암, 작은 섬은 다음과 같이 입력해야함.

.노출암, 작은 섬의 입력
[cols="10,50", options="header"]
|===
|Primitives |Feature

h| Surface
| span:F[Land Area][S] (필수) +
span:F[Coastline][C] or span:F[Shoreline Consturction][C] (필수) +
span:F[Land Elevation][P] (선택 사항)

h| Point
| span:F[Land Area][P] (필수) +
span:F[Land Elevation][P] (선택 사항)
|===

* span:F[Land Area][P] 위에 아래 객체를 입력하려는 경우 span:A[in the water]에 관한 설명을 참고 해야함 <<inTheWater,※참고>>
** span:F[Building]
** span:F[Built Up Area]
** span:F[Crane]
** span:F[Fortified Structure]
** span:F[Landmark]
** span:F[Silo Tank]
** span:F[Wind Turbine]
