===== Remark
* span:F[Vertical Datum of Data]는 필수 메타 객체로, 반드시 하나 이상 입력해야 하고, 데이터가 존재하는 모든 영역을 빈틈없이 덮도록 입력해야 함
** span:F[Vertical Datum of Data]끼리 중첩되는 영역이 있으면 오류
** 다른 필수 메타 객체인 span:F[Sounding Datum]과는 중첩될 수 있음
* 국내의 경우 span:A[Vertical datum] = 3 span:D[mean sea level] 으로 인코딩하는 것이 일반적
** 영역 내에서 개별 객체가 사용하는 기준면이 다른 경우는 해당 객체의 span:A[vertical datum]을 반드시 입력해야 함 +
   예) 교량의 안전통과높이(약최고고조면 기준)


===== Example
.Vertical Datum of Data의 인코딩 예시

|Attribute |Acronym |Type |Mult. |Value

|span:E[vertical datum]|VERDAT|EN|1,1| 3 span:D[mean sea level]
