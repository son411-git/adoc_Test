=== 2. 객체 관계 인코딩 지침

==== Refer
// tag::Refer[]
//
* {ObjectName} 입력할 때에는, 반드시 {Relation} 관계에 포함되어야 함 (<<{linkTo},※참고>>)
// end::Refer[]

==== AtoN_Relationship
// tag::AtoN_Relationship[]
//
* span:F[Fog Signal], span:F[Radar Transponder Beacon] 및 등화 등 장비 역할의 객체들이 있다면 span:R[Structure/Equipment] 관계 설정
// end::AtoN_Relationship[]

=== 3. 필수 객체/속성 인코딩 지침

==== surroundingDepth
// tag::SurroundingDepth[]
//
**span:E[주의]**:: ECDIS System 속성인 span:A[surrounding depth]를 필수로 입력해야 함
* span:A[surrounding depth]의 값은 객체를 완전히 덮기 위해 필요한 모든 span:F[Depth Area] 및 span:F[Dredged Area] 중 **가장 깊은 영역**의 span:A[depth range minimum value]와 같게 입력
* span:A[default clearance depth]의 값은 <<{linkTo}>> 참고하여 입력
** 표에서 Least Depth는 값은 객체를 완전히 덮기 위해 필요한 모든 span:F[Depth Area] 및 span:F[Dredged Area] 중 **가장 얕은 영역**의 span:A[depth range minimum value]와 같은 값을 의미
// end::SurroundingDepth[]

=== 4. 선택적 객체/속성 인코딩 지침

==== Beacon_Attr_General
// tag::Beacon_Attr_General[]
//
* 입표(Beacon)의 span:A[height]는 등대표에 기재되어 있지 않으며, 일반적으로 입력하지 않음
* span:A[vertical length]는 지면에서 구조물 최상단까지의 높이를 입력 (등대표에 기재된 구조물 높이를 입력)
// end::Beacon_Attr_General[]

==== Buoy_Attr_General
// tag::Buoy_Attr_General[]
//
* 부표(Buoy)의 span:A[height]와 span:A[vertical length]는 일반적으로 입력하지 않음
// end::Buoy_Attr_General[]

==== colourPattern
// tag::colourPattern[]
//
* 객체에 여러 색상을 입력해야 하는 경우, span:A[colour pattern] 및 span:A[colour] 속성을 다음과 같이 사용해야 함 (<<Colour_Pattern,※참고>>)
// end::colourPattern[]

==== featureName
// tag::featureName[]
//
* 객체의 명칭을 입력해야하는 경우 span:A[featureName] 속성을 다음과 같이 사용해야 함 (<<featureName,※참고>>)
// end::featureName[]

==== featureName_for_AtoN
// tag::featureName_for_AtoN[]
//
* 항로표지의 명칭은 <<Structure_Equipment_featureName,링크>>를 참고
** 명칭에서 등대, 등부표, 입표 등 항로표지의 유형은 생략하고 입력 (예 : 서이말 등대 → 서이말)
** 영문은 등대표의 영문 명칭을 입력하며 제A호, 제1호 등의 번호가 있는 경우 No A, No 1로 입력 (예 : Hupo No A) 
// end::featureName_for_AtoN[]

==== IALA_Warning
// tag::IALA_Warning[]
//
* 현장에 설치된 항로표지나 등화의 속성이 IALA 해상부표식과 다를 경우 또는 관련 기관의 고시, 항행통보, 유효성 검사 도구 등을 통해 이를 확인한 경우, 제작자는 **반드시** 국립해양조사원에 보고해야 함
// end::IALA_Warning[]

==== information
// tag::information[]
//
* 해당 객체의 추가 정보는 span:A[information] 또는 span:F[Nautical Information]을 사용하여 입력
** span:A[information/text]는 300자를 초과할 수 없음
** span:A[information/text]가 300자를 초과할 경우, 반드시 span:A[information/file reference]를 사용해야 함
* 항해 안전과 관련된 내용은 span:F[Caution Area]를 사용
// end::information[]

==== speedLimits
// tag::speedLimits[]
* 모든 선박 또는 특정 선박 등급에 대해 속력 제한이나 항주파 제한이 설정된 경우 다음과 같이 입력해야 함 (<<Speed_Limits,※참고>>)
// end::speedLimits[]


==== vertical clearance의 vertical datum
// tag::verticalDatum_for_clearance[]
//
** 이 높이는 수직기준면이 다른 객체와 다르므로, span:A[vertical datum]를 필수로 입력해야 함
** 표준에서는 최고천문조위(HAT; Highest Astronomical Tide)를 기준으로 사용할 것을 권고하고 있지만, 국내에서는 약최고고조면을 기준으로 하기 때문에, span:A[vertical datum]는 29 span:D[nearly highest high water]로 입력
// end::verticalDatum_for_clearance[]
