// tag::SpecialPurposeGeneralBeacon[]
===== Remark
* 특수/일반 입표는 span:F[Special Purpose/General Beacon]로 입력
** 일반적으로 황색 구조물/황색 'X'자 형태의 두표를 가짐
*** 두표(top mark)가 다색/패턴이고, 항해에 매우 중요한 정보라면 두표를 span:F[Daymark]로 입력

:ObjectName: span:F[Special Purpose/General Beacon]을
:Relation: span:R[Structure/Equipment]
:linkTo: Structure_Equipment
include::common/phrase.adoc[tag=Refer]
* 장비(등화, 무신호, AIS 등)를 탑재한 경우, 해당 객체와 span:F[Special Purpose/General Beacon]간 span:R[Structure/Equipment] 관계 설정

//
* 등대표, 항행통보 문서 등을 참고하여 명칭과 도색·구조·높이를 입력
** 명칭을 span:A[feature name]의 span:A[name]을 입력할 때 '입표', '등표'는 입력하지 않음
** 등대표의 도색·구조·높이 중 높이는 구조물의 수직길이를 의미하므로, span:A[vertical length]에 입력

* 항로표지 정보의 입력은 <<ListOfLights,링크>>를 참고

명칭:: '등표'를 제외한 **포항항 포스코 케미칼 취수탑**만 입력

등질, 등고, 광달거리:: 이 세가지 항목은 구조물의 속성이 아님 ( span:F[Light All Around]나 span:F[Light Sectored]로 입력해야 함 ) +
**[참고]** 등고를 span:F[SpecialPurposeGeneralBeacon]의 span:A[height]나 span:A[elevation]에 입력한 것은 오류

도색·구조·높이:: 도색이 '황'색이므로 span:A[colour]를 6 span:D[yellow]으로 입력 +
구조는 '원형 철조'이므로 span:A[nature of construction]을 7 span:D[metal]로 입력 +
높이가 12이므로 span:A[vertical length]를 12span:D[m]로 입력

기타:: 등대표에서 확인할 수 없는 정보는 항행통보 문서 등을 확인하여 입력 +
입표의 모양(span:A[beacon shape])이나 두표의 존재 여부 등
