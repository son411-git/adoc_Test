===== Remark

* 항해가 가능한 수역을 지나는 가공관을 입력해야하는 경우, 반드시 span:F[Pipeline Overhead]를 사용해야 함
//
* 통과 가능 높이는 span:A[vertical clearance fixed]로 입력
include::common/phrase.adoc[tag=verticalDatum_for_clearance]

//
* 사용하지 않는 가공관은 span:A[status] = 4 span:D[not in use]로 입력하고, span:A[category of pipeline/pipe] 및 span:A[product] 속성은 입력하지 않음

//
* 가능하다면, 가공관을 지지하는 구조물은 span:F[Pylon/Bridge Support]로 인코딩하고, span:A[category of pylon] = 6 span:D[pipeline pylon]으로 입력해야 함

===== Example
.Pipeline Overhead의 인코딩 예시
[cols="30,25,10,10,25", options="header"]
|===
|Attribute |Acronym |Type |Mult. |Value

|category of pipeline/pipe|CATPIP|EN|0,1| 6 span:D[supply pipe]
|product|PRODCT|EN|0,*| 3 span:D[water]
|**vertical clearance fixed**|VERCLR|C|0,1|
|    span:E[vertical clearance value]|VERCLR|(S)RE|1,1| _(Unknown)_

|===
