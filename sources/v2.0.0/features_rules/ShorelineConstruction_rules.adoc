===== Remark
* 부두, 잔교, 돌제, 방파제, 제방, 안벽과 방사제 등의 인공 해안선은 span:F[Shoreline Construction]으로 입력
** span:F[Shoreline Construction]를 Surface로 입력한 경우, Line 타입을 추가로 인코딩할 필요는 없음 //REVIEW: 이게 굳이?
** span:F[Shoreline Construction]이 SoE 객체 중 span:F[Land Area]에 포함되는 경우, span:A[water level effect] = 2 span:D[always dry]로 입력
** span:F[Shoreline Construction]과 SoE 객체 중 span:F[Depth Area]와 중첩되는 경우, 수면과의 관계에 따라 span:A[water level effect]를 구분하여 입력
** 구조물의 재질을 알 수 있는 경우, 가급적 span:A[nature of construction]을 이용해 입력


- 현재 국내 전자해도에는 <표 A>의 3~9번 속성 조합을 구분하여 인코딩하고 이외에는 일반적으로 1번 또는 2번으로 인코딩
