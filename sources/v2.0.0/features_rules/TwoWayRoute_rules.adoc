// tag::TwoWayRoute[]
===== Remark

** 양길항로는 span:F[Two-Way Route][S]로 입력하고 이름은 span:A[Feature name]에 입력

* span:F[Two-Way Route]는 반드시 하나 이상의 span:F[Two-Way Route Part]와 연관 관계를 설정해야 함
** 항로의 각도에 따라 별도의 객체를 생성하여 두 개 이상의 양길항로부가 하나의 항로를 나타낼 경우, span:F[Two-Way Route]와 span:R[Two-Way Route Aggregation] 관계 설정(<<TWRT_AGGR,※참고>>)

===== Example
.Two-Way Routet의 인코딩 예시
[cols="30,25,10,10,25", options="header"]
|===
|Attribute |Acronym |Type |Mult. |Value
|**Feature Name**||C|0,*| 
|    span:E[language]||(S)TE|1,1| eng
|    span:E[name]|OBJNAM/NOBJNM|(S)TE|1,1| Wonjeon fairway
|    Name Usage||(S)EN|0,1| 1 span:D[default name display]
|**Feature Name**||C|0,*| 
|    span:E[language]||(S)TE|1,1| kor 
|    span:E[name]|OBJNAM/NOBJNM|(S)TE|1,1| 원전항로
|    Name Usage||(S)EN|0,1| 2 span:D[alternate name display]
|===
