// tag::TidalStreamFloodEbb[]
===== Remark
* span:A[category of tidal stream]를 이용하여 창조류와 낙조류를 구분하여 입력
** 창조류 : span:A[category of tidal stream] = 1 span:D[flood stream]
** 낙조류 : span:A[category of tidal stream] = 2 span:D[ebb stream]

//
* 조류의 속도는 span:A[speed]를 이용하여 입력
** span:A[speed maximum]에는 최강유속을 노트(knots) 단위로, 소수점 첫째 자리까지 표현

//
* 조류의 방향은 span:A[orientation]을 이용하여 입력
** span:A[orientation value]에 조류에 대한 방위각을 입력

===== Example
.Tidal Stream Flood Ebb의 인코딩 예시
[cols="30,25,10,10,25", options="header"]
|===
|Attribute |Acronym |Type |Mult. |Value
|**span:E[orientation]**||C|1,1|
|    orientation uncertainty||(S)RE|0,1| 
|    span:E[orientation value]|ORIENT|(S)RE|1,1| 178
|**span:E[speed]**||C|1,1|
|    span:E[speed maximum]|CURVEL|(S)RE|1,1| 1.3 span:D[knots]
|    speed minimum||(S)RE|0,1|
|===
