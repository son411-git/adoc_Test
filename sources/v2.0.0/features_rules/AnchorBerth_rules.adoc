// tag::AnchorBerth[]
===== Remark

* 고시로 정의되는 단일 선박을 위한 지정 정박지일 경우 span:F[Anchor Berth]를 사용하여 입력하며, 기본적으로 점(Point) 형태로 입력
* 중심 좌표와 반경이 제시되어 있으면 점(Point) 형태로 입력하고 span:A[radius]을 입력 
* span:F[Anchor Berth]의 이름이나 숫자는 span:A[feature name]에 입력, 단 다수의 span:F[Anchor Berth]가 공통의 이름을 갖는다면 span:F[Sea Area/Named Water Area] 으로 입력
