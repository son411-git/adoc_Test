// tag::InformationArea[]
===== Remark

해도 간행 정보::
* 기준 축척 종이해도의 간행정보 및 보정도 정보를 입력하는데 사용
* 개정 시 종이해도의 간행 정보를 업데이트하고 보정도와 관련된 span:F[Information Area]는 삭제
* span:F[Information Area]에 해도명과 발행일을 입력하고 해도의 적용 자료 등 추가 정보는 span:A[information] 또는 span:F[Nautical Information]에 입력하여 span:R[Additional Information Association]을 설정

//

일반적인 정보::
* 종이해도에 주의기사를 입력할 때에는 항해안전을 위한 정보 제공 목적인지, 일반 정보 제공 목적인지 구분해야 하여 span:F[Caution Area] 또는 span:F[Information Area]로 입력해야 함 +
또한, 셀 구역 전체에 입력하는 것을 피해야함

* 아래 나열된 주의기사 내용은 대상 객체 주변에 span:F[Caution Area][P,C,S]를 입력하고 span:A[information]또는 span:F[Nautical Information] 관련 정보를 입력
** 공사중, 매립중, 미측 구역, 송전선, 안벽, 암초, 항해주의, 잠수정, 선박횡단, 고도제한, 사주, 사퇴, 모래톱, 좌주, 토사 등 항해 안전에 직접적인 영향을 미치는 내용

* 위에 언급되지 않은 난외 기사의 내용은 span:F[Information Area]에 입력하거나 해도 상 관련 객체의 span:A[information]에 입력
** 해도 상 관련 객체가 여러 개이며, 동일한 내용을 입력해야 할 경우 span:F[Nautical Information]에 에 입력하여 span:R[Additional Information Association]을 설정

//
* 객체의 이름을 ECDIS에 표시할 필요 없으므로 span:A[name usage]를 입력하지 않아야 함

* span:A[fixed date range]의 하위 속성 span:A[date end]의 날짜가 지난 경우, span:F[Information Area]는 삭제해야 함
