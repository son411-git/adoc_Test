===== Remark

* 추천항로는 span:F[Recommended Track]으로 입력
** span:A[orientation value]와 span:A[traffic flow]로 통항 방향을 입력
** 변침이 필요한 경우는 span:F[Recommended Track]을 분할하여 통항 방향을 각기 입력

//
* 고정된 물표나 등화로 추천항로를 나타내는 경우는 span:F[Navigation Line]등과 연관관계를 가짐
//REVIEW: 참고 링크 추가해야 함
