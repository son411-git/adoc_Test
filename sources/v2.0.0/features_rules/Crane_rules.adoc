// tag::Crane[]
===== Remark

* span:A[orientation]은 크레인 축의 방향을 방위각으로 입력 (일반적으로 부두에 수직 방향)
* 이동식 크레인의 선로는 span:F[Railway]로 입력
* 등화가 입력된 경우 span:F[Crane]을 Sturture 역할로 span:R[Structure/Equipment] 관계를 맺어야 함
* 가항 수역에 위치한 크레인은 span:A[in the water] = (true) 로 입력, 이때 span:F[Pile]과 같은 지지 구조물은 입력할 필요가 없음
* 항해 계획 및 모니터링에 중요하다고 판단하는 경우, span:A[vertical clearance fixed]와 span:A[vertical uncertainty]를 입력할 수 있음
* span:A[lifting capacity]은 톤(Tonne, t) 단위로 입력
