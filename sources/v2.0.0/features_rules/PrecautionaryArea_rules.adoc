===== Remark

* span:F[Precautionary Area]는 주로 항로의 교차점이나 항로와 다른 수역이 만나는 지점 등에서 선박의 안전한 통항을 위해 주의를 요하는 구역을 나타냄
* span:F[Precautionary Area]는 통항분리제도(Traffic Separation Scheme)의 일부로 사용될 수 있으며, 이 경우 span:R[Traffic Separation Scheme Aggregation] 연관 관계에 포함되어야 함 (<<TSS_AGGR,※참고>>)
** span:F[Precautionary Area]는 통항분리제도를 구성하는 다른 객체(예; Traffic Separation Lane Part)와 함께 사용될 수 있음
** TSS에 포함되는 경우 span:A[imo adopted] 속성은 입력하지 않음 
//
* span:F[Precautionary Area]를 입력할 때에는 반드시 span:A[information]에 주의해야 하는 사항에 대한 설명을 입력해야 함

===== Example

|    text|INFORM/NINFOM|(S)TE|0,1| 이 구역에서는 항로를 횡단하는 소형선박이 많으므로 주의하여 항행하여야 함.

|===
