===== Remark

* span:F[Mooring Buoy]는 적절한 축척의 해도에 반드시 표시해야 함. 
** 이는 부표와 계류된 선박이 항해에 잠재적 위험 요소가 될 수 있음을 알리고, 가장 큰 축척에서는 계선 작업을 용이하게 하기 위함임.
* 방문객 계선부표(visitors mooring)를 인코딩해야 하는 경우, span:A[visitors mooring] = (True)로 입력해야 함.
