===== Remark

* span:F[Quality of Survey]는 해당 개별적인 측량 성과의 품질을 나타내며, span:F[Quality of Bathymetric Data]와는 다름
** span:F[Quality of Survey]는 필수적으로 입력해야하는 메타 객체는 아님
** 측량원도의 축척에 대응되는 가장 대축척 자료에만 입력
** 측량원도의 축척을 span:A[scale value maximum]으로 입력
** 과업의 시작, 종료일을 span:A[survey date range]의 span:A[date start]와 span:A[date end]로 입력
** 원도 번호를 span:A[information]의 span:A[text]로 입력
