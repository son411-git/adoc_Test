===== Remark

* span:A[orientaion value]는 필수 속성은 아니지만, 추천항로 중심선의 방향을 계산해서 입력
** 일방 통행인 경우(span:A[traffic flow] = 1,2,3), 선의 방향과 일치
** 양방 인 경우(span:A[traffic flow] = 4), 하나의 값만 입력할 수 있으므로, 180° 미만인 쪽의 값을 입력

//
* 고정된 물표나 등화로 추천항로를 나타내는 경우는 span:F[Navigation Line]등과 연관관계를 가짐
//REVIEW: 참고 링크 추가해야 함
