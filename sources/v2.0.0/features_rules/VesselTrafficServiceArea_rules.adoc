// tag::VesselTrafficServiceArea[]
===== Remark
//REVIEW: 대공사
* VTS 관제구역이 무선보고선과 연관되었다면 span:F[Radio Calling-In Point]를 경계로 사용하는 span:F[Vessel Traffic Service Area]를 반드시 입력

* VTS 관제구역이 무선보고선과 연관되었다면 span:A[communication Channel]은 span:F[Contact Details]에 입력

* span:F[Radio Calling-In Point]가 VTS 관제 구역과 직접적으로 연관되지 않은 독립적인 지점이라면, span:F[Vessel Traffic Service Area] 없이도 입력 가능
** 반대의 경우도 가능
 
** 이 때, span:F[Vessel Traffic Service Area]의 span:A[feature name] 속성은 span:F[Radio Calling-In Point]의 span:A[feature name] 속성과 동일한 VTS센터명를 입력해야 함 
* span:A[feature name] 속성은 보고지점을 지정한 주체의 이름을 입력 (예 : '완도') +
  단, span:F[Vessel Traffic Service Area]의 경우 묘화에서 명칭 앞에 'VTS'가 접두사로 붙으므로 'VTS'는 입력하지 않지만 (예: '완도 VTS' → '완도'), + 
  span:F[Radio Calling-In Point]의 경우에는 'VTS'를 포함하여 입력 (예: '완도 VTS') 

//
** 동일한 채널을 사용하는 span:F[Radio Calling-In Point]가 여러 개 있는 경우, span:F[Contact Details]에 속성 span:A[communication channel]에 채널을 입력하고, +
    span:F[Vessel Traffic Service Area], span:F[Radio Calling-In Point]와 span:F[Contact Details] 간 연관관계를 설정

*  span:F[Vessel Traffic Service Area], span:F[Radio Calling-In Point] 는 제품에서 span:F[LandArea]를 포함하거나 중첩되지 않아야 함
