===== Remark

* span:F[Dry Dock]는 반드시 span:F[Land Area]로 덮여있어야 함
* span:F[Dry Dock]의 경계는 span:F[Coastline] 또는 span:F[Shoreline Construction]으로 입력되어서는 안 되며, 예외적으로 span:F[Gate]은 입력할 수 있음
* span:F[Dry Dock]의 입구가 열려 있는 상태에서 항행 가능한 부분의 공식적인 여유 길이와 너비는 span:A[horizontal clearance length]와 span:A[horizontal clearance width]를 사용하여 입력
** 필요 시, span:F[Dry Dock] 자체의 최소 물리적 길이와 너비는 span:A[horizontal length]와 span:A[horizontal width]을 사용하여 입력
