===== Remark

* span:F[Oil Barrier]은 유류 유출/확산 방지를 위한 설비
** 국내에서는 해상공사 시 오염 방지를 위해 사용하는 오탁방지막까지 확장해서 사용
** span:F[Oil Barrier]는 Curve 형태로 입력
** 공사를 위해 일시적으로 설치된 경우, span:A[condition] = 7 span:D[temporary]로 입력
** 오탁 방지막인 경우, span:A[category of oil barrier] = 2 span:D[floating oil barrier]로 입력

===== Example
.Oil Barrier의 인코딩 예시
[cols="30,25,10,10,25", options="header"]
|===
|Attribute |Acronym |Type |Mult. |Value

|category of oil barrier|CATOLB|EN|0,1| 2 span:D[floating oil barrier]
|condition|CONDTN|EN|0,1| 7 span:D[temporary]

|===
