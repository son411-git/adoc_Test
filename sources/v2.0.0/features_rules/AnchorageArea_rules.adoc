// tag::AnchorageArea[]
===== Remark

* 명확한 경계가 없는 추천 정박지는 span:F[Anchorage Area][P]로 입력하고 span:A[category of anchorage] = 1(unrestricted anchorage), span:A[status] = 3(recommended)으로 입력
* 관계기관에 의해 정의되지 않았으나 정박지로 보고된 곳은 점(Point) 형태로 입력해야하며, span:A[category of anchorage] = 15 span:D[reported anchorage]로 입력 
* 다수의 소형선이 계류 장소가 있는 정박지구역의 경우 span:F[Mooring Area][S]로 입력하고 span:A[category of mooring area] = 1 span:D[small craft mooring area]로 입력
* 임시정박지의 경우 span:A[category of anchorage] = 1 span:D[unrestricted anchorage]로 입력하고 span:A[status] = 7 span:D[temporary]로 입력
