===== Remark
* span:F[Current Non-Gravitational] 은 방향이 일정하고 천문 조건(중력)에 의존하지 않는 물의 움직임으로, 흐르는 방향으로 표시됨
* 최대 유속은 노트(knots) 단위를 사용하며 소수점 첫째짜리까지 span:A[speed maximum]에 입력
** 강도가 변하면 span:A[speed minimum]도 함께 명시
* 유향은 방위각으로 소수점 둘째짜리까지 span:A[orientation value]에 입력너무 변동적이면 span:A[orientation value] = (UNKNOWN)으로 설정
* 계절적 변동은 span:A[periodic date range]로 표시.
* span:A[periodic date range]에 해당하는 값이 있거나, 간헐적으로 발생하는 해류에는 span:A[status] = 5 span:d[periodic/intermittent] 입력

include::common/information.adoc[]

===== Example

.일반적인 해류의 인코딩 예시
[cols="30,25,10,10,25", options="header"]
|===
|Attribute |Acronym |Type |Mult. |Value

|**span:E[orientation]**||C|1,1|
|    orientation uncertainty||(S)RE|0,1|
|    span:E[orientation value]|ORIENT|(S)RE|1,1|60
|**span:E[speed]**||C|1,1|
|    span:E[speed maximum]|CURVEL|(S)RE|1,1|2.5
|    speed minimum||(S)RE|0,1|1.5

|===

.주기적 날짜 범위(periodic date range)가 있는 해류의 인코딩 예시
[cols="30,25,10,10,25", options="header"]
|===
|Attribute |Acronym |Type |Mult. |Value

|**span:E[orientation]**||C|1,1|
|    orientation uncertainty||(S)RE|0,1|
|    span:E[orientation value]|ORIENT|(S)RE|1,1|183
|**periodic date range**||C|0,*|
|    span:E[date end]|DATEND|(S)TD|1,1|----03--
|    span:E[date start]|DATSTA|(S)TD|1,1|----01--
|**span:E[speed]**||C|1,1|
|    span:E[speed maximum]|CURVEL|(S)RE|1,1|4.5
|    speed minimum||(S)RE|0,1|2.5
|status|STATUS|EN|0,1|5 span:d[periodic/intermittent]

|===
