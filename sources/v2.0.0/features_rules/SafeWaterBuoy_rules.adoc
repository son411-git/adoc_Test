===== Remark

* 안전수역 부표는 표지 주변이 항행가능한 수역임을 나타내는 표지로 항로의 중심선이나 최적 항로를 표시하기 위한 목적으로 사용
* IALA 부표식을 따르는 경우 아래와 같은 특성을 가짐
** 모양은 구형span:D[spherical] 또는 망대형span:D[pillar] 또는 원주형span:D[spar]
** 부표의 색은 홍백종선
** 등화의 색은 백색
** 등질은 Oc span:D[occulting] 또는 Iso span:D[Isophased] 또는 LFl(1) span:D[Long flashing] 또는 Mo(A) span:D[Morse]
** 주기는 10s

:ObjectName: span:F[Safe Water Buoy]를
:Relation: span:R[Structure/Equipment]
:linkTo: Structure_Equipment
include::common/phrase.adoc[tag=Refer]
* 장비(등화, 무신호, AIS 등)를 탑재한 경우, 해당 객체와 span:F[Special Purpose/General Beacon]간 span:R[Structure/Equipment] 관계 설정

//
* 항로표지 정보의 입력은 <<ListOfLights,링크>>를 참고

//=> 등대표 상에 기술된 내용과 다르지 않다면, 해당 오류는 무시해야 함

**비고**:: span:F[Safe Water Buoy]의 특성이 IALA 부표식과 다른 경우 자동검사 S/W에서 오류로 탐지하기도 하나, 등대표의 내용과 일치한다면 해당 오류는 무시해야 함
