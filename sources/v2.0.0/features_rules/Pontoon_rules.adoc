===== Remark

* span:F[Pontoon] 객체는 반드시 span:F[Depth Area], span:F[Dredged Area], 또는 span:F[Unsurveyed Area]와 중첩되어야 함.
* span:F[Pontoon][S]의 경계에 span:F[Coastline] 또는 span:F[Shoreline Construction]을 입력해서는 안 됨 ( 단, 라인이 span:F[Land Area][S]의 경계와 일치하는 경우는 예외. )

//REVIEW: 아래 내용은 잘 못된 내용임;
// * 육지와 부잔교를 연결하는 다리의 경우 #F "Bridge"로 입력하고 #A "Category of bridge" = 3(pontoon bridge) 입력  ※ Briddge 인코딩 기준 참조

span:addition[비고]:: span:F[Bridge]의 span:A[category of bridge] 속성은 3 span:D[pontoon bridge] 변경되었음
span:A[bridge construction] 중 3 span:D[pontoon bridge]는 실제로 Pontoon으로 지지하는 교량을 말하기 때문에, 부잔교와 육상을 연결하는 다리까지 포함해서 span:F[Pontoon]으로 입력할 것을 제안
