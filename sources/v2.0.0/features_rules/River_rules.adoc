// tag::River[]
===== Remark

* 편집 축척에서 항해가 불가능한 구역이라면 span:F[River]로 입력
** 항해가 가능한 구역이라면, span:F[Depth Area]나 span:F[Dredged Area], span:F[Unsurveyed Area]로 입력 span:D[이 때는 River로 입력하지 않음]
*** 이 경우, 경계는 span:F[Coastline] 이나 span:F[Shoreline Construction]으로 적절히 표현해야 함
*** 이 경우, 강의 명칭을 입력할 때는 span:F[Sea Area/Named Water Area]를 입력하고, span:A[category of sea area]를 53 span:D[river]로 설정한 후 span:A[feature name]으로 명칭을 입력
* 간헐천은 span:A[status] = 5 span:D[periodic/intermittent]로 입력

//
* 육상의 강에 포함되는 섬을 입력할 때는 span:F[River][S]의 내부 링으로 표현span:D[이 때는 별도의 Land Area를 입력해서는 안 됨] 하거나 span:F[Land Area][P]로 입력
