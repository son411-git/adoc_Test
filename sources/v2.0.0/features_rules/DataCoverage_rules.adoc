===== Remark

* span:F[Data Coverage]는 데이터셋 내 데이터가 적용된 공간적 범위와 동일한 영역을 커버해야 하며, 겹쳐서는 안 됨
** 또한, span:F[Data Coverage]는 ECDIS에서 사용자가 선택한 화면 축척에 따라 데이터셋 로딩과 렌더링을 결정하는 데 필요한 축척 정보를 제공함
* 최소한 하나의 span:F[Data Coverage] 가 데이터셋에 포함되어야 함

* 전자해도의 축척에 따라 ECDIS에 표시하기 위해 입력되는 축척 정보는 아래와 같이 3개의 속성이 있으며, 속성 값은 <<DataCoverage_F1,[그림 - 최대/적정/최소 표시 축척의 값]>>에 명시된 값만을 사용해야 함

//
* span:A[optimum display scale] (적정 표시 축척) 설정
** S-101 Annex A, Table 3-2에서 정의된 값 중 편집 축척보다 한 단계 큰 값을 선택
** 예: 1:5,000 편집 축척 → span:A[optimum display scale] = (4000)

//
* span:A[minimum display scale] (최소 표시 축척) 설정
** span:A[optimum display scale] 보다 큰 값을 선택해야 함
** 보통 다음 축척 단계의 span:A[optimum display scale] 값과 일치하도록 설정
** 예: 1:5,000 편집 축척 → span:A[minimum display scale] = (8000)

//
* span:A[maximum display scale] (최대 표시 축척) 설정
** span:A[optimum display scale] 보다 작은 값 또는 동일한 값으로 설정 가능
** 일반적으로 span:A[optimum display scale]의 절반 정도 값 선택
** 예: 1:5,000 편집 축척 →span:A[maximum display scale] = (2000)

// 
* 주의사항
** 하나의 데이터셋에 다수의 span:F[Data Coverage]가 있는 경우:
*** span:A[minimum display scale]은 모두 동일해야 함
*** span:A[optimum display scale]은 다를 수 있음
*** span:A[maximum display scale]은 다를 수 있음

// 
NOTE :
**2025년 S-101 DB 구축 TF 결정 사항** : +
국내 전자해도 제작 시 기본 편수 자료의 단계별 축척 일관성이 높아지고 S-57 메타 객체 span:F[M_CSCL]의 사용이 점차 줄어듦에 따라 +
데이터 편집 축척을 구분하기 위한 목적으로 S-101에서 span:F[Data Coverage]를 사용하지 않으며, S-57 span:F[M_CSCL]로도 변환하지 않음
