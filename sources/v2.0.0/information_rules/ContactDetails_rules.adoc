// tag::ContactDetails[]
===== Remark

* 연락처 정보(통신 채널, 호출 부호, 무선 주파수 등)를 입력해야 하는 경우, span:F[Contact Details]를 반드시 사용해야 함. 각 span:F[Contact Details]는 적용되는 객체와 span:R[Additional Information]을 통해 반드시 연관되어야 함

//
* 선박이 신호를 수신하는 주파수는 span:A[frequency pair]의 하위 속성 span:A[frequency shore station transmits]를 사용하여 반드시 입력해야 함
* 선박이 해안으로 신호를 보내는 주파수는 span:A[frequency pair]의 하위 속성 span:A[frequency shore station receives]를 사용하여 반드시 입력해야 함
* span:A[frequency pair]에 채워지는 값은 헤르츠(Hz) 단위로 반드시 명시해야 함
** 예를 들어, 950 MHz의 신호 주파수는 950000000으로 입력해야 함

//
* 호출 부호는 span:A[call sign] 속성으로 입력
* VTS센터와 선박 간 통신 채널은 span:A[communication channel] 로 입력하며 VHF 채널 7일 경우, [VHF####] 형식으로 대괄호를 포함하여 입력해야 함
* 선박의 보고 내용(신고 내용)은 span:A[contact instructions] 으로 입력 
* 기타 통신 수단(전화번호, 팩스번호 등)은 span:A[telecommunications]의 하위 속성으로 입력
** 통신 수단 식별자는 span:A[telecommunication identifier] 속성으로 입력하며 국가번호를 포함한 전체 번호를 입력
** 통신 서비스 종류는 span:A[telecommunication service] 속성으로 입력하며, 음성 통화는 1 span:D[voice], 팩스는 2 span:D[facsimile]로 입력
