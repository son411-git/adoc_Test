===== Remark

//

* span:R[Spatial Association]은 span:F[Spatial Quality]와 연관된 지리적 형상(점, 선, 면)를 적어도 하나 반드시 포함해야 함. 
** 여러 객체가 하나의 지리적 형상(점, 선, 면)과 연관된 경우, span:F[Spatial Quality]은 연관된 모든 객체에 적용됨.
* 면(surface) 형태 객체를 다룰 때는, 그 구역의 경계를 이루는 선(curve)들에 span:F[Spatial Quality]를 반드시 연결해야 함.
