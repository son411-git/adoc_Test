===== Remark

* 일반적으로 span:F[Mooring Trot]은 다음으로 구성됨:
** 최소 하나의 span:F[Berth]
** 최소 두 개의 span:F[Cable Submarine]
** 최소 두 개의 span:F[Mooring Buoy]
** 최소 두 개의 span:F[Obstruction]
//
* span:R[Mooring Trot Aggregation]은 **The Component** 역할에 나열된 객체 중 최소 하나를 반드시 포함해야 하며, 이는 span:F[Mooring Trot]과 관계를 맺어야 함
