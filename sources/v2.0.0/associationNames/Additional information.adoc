===== Remark

* span:R[Additional Information]을 구성하는 객체는 **The Information** 역할에 포함된 하나 이상의 해당 **Information Type(정보 유형)**과 연관된 다음 목록에 포함된 **Feature Type(객체 유형)** 중 최소 하나를 반드시 포함해야 함
