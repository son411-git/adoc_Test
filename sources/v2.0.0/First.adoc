== GENERAL
//
*Definition*

* 객체의 정의입니다. IHO S-32 수로사전 등을 참조합니다.

//
*Primitives*

* 객체의 지오메트리 유형입니다. 본문에서는 다음과 같이 사용됩니다.
** [P] : Point
** [C] : Curve
** [S] : Suface
** [N] : None
* 예를들어, span:F[Land Area][P,S]는 점(Point) 형태의 span:F[Land Area]와 면(Surface) 형태의 span:F[Land Area]를 의미합니다.

//
*Attribute*

* 속성은 단순 속성(Simple Attribute)과 복합 속성(Complex Attribute)으로 나뉩니다.
* 복합 속성은 **검정색 굵은 글꼴**로 표기하고 Type에는 Complex의 "C"를 표기했습니다.
* 복합 속성의 하위 속성(Sub-Attribute)은 들여쓰기를 하고 Type에는 Sub의 "(S)"를 표기했습니다.
* 필수 속성은 span:E[빨간색 굵은 글꼴]로 표기했습니다.

.복합 속성 feature name의 예시
[cols="25,25,10,10", options="header"]
|===
|Attribute |Acronym |Type |Mult.
|**feature name**||C|0,*
|    span:E[language]||(S)TE|1,1
|    span:E[name]|OBJNAM/NOBJNM|(S)TE|1,1
|    name usage||(S)EN|0,1
|===

//
*Acronym*

* S-57 ENC에서 사용하는 일반적인 6자리 객체/속성 약어(Object Acronym) 입니다. 

* 영문과 국문의 입력이 나뉘어져 있던 속성은 "/"로 구분하여 표기했습니다.
** OBJNAM/NOBJNM , INFORM/NINFOM , TXTDSC/NTXTDS

//
*Type*

속성의 **자료형(Type)**은 해당 속성에 어떤 형식의 값이 입력되어야 하는지를 정의합니다.

.Type의 표기법
[cols="1,2,7" options="header"]
|===
| 약어 | 자료형 | 설명
| BO | Boolean | (True) 또는 (False) 논리값을 입력합니다. +
선택값에 따라 다른 속성 입력이 필수일 수 있습니다.
| EN | Enumeration | 미리 정의된 목록에서 값을 선택합니다. +
객체에 따라 허용된 값이 다르므로, 해당 목록을 확인해야 합니다 +
(예: span:A[condition], span:A[status], span:A[restriction]).
| RE | Real | 실수를 입력합니다. 소수점 이하 자리수는 속성에 따라 다릅니다.
| IN | Integer | 정수를 입력합니다.
| TD | Truncated Date | YYYYMMDD 형식의 날짜를 입력하며, 일부 날짜 표현도 가능합니다. +
(예 : 매년 3월 → pass-format:all[----03--])
| TE | Text | 문자열을 입력합니다. 속성마다 문자 유형과 길이 제한이 다르며, +
시작/끝 공백 및 줄바꿈은 절대 포함 불가합니다.
| TI | Time | HHMMSS+UTC 형식으로 시간을 입력합니다 +
(예: 오후 7시 32분 → 193200+0900).
| URI | Universal Resource Identifier | URL 형태로 자원을 식별합니다 +
(예: https://registry.iho.int)
| URN | Universal Resource Name | 해양 자원 식별 이름(MRN: Maritime Resource Name)을 입력합니다. +
(예: urn:mrn:iho:s101:2:0:0:AnchorageArea)
|===

//
*Multiplicity*

Multiplicity는 각 속성이 가질 수 있는 값의 개수(수량적 제약)를 정의합니다. +
이는 해당 속성이 필수인지, 반복 가능한지 등을 명확히 하여 데이터 입력 규칙을 설정합니다.

.Multiplicity의 표기법
[cols="1,9" options="header"]
|===
| 0,1 | 해당 속성은 선택 사항이며, 최대 한 개의 값만 입력할 수 있습니다.
| 0,* | 해당 속성은 선택 사항이며, 0개 이상 여러 개의 값을 입력할 수 있습니다.
| 1,1 | 해당 속성은 필수 항목이며, 정확히 한 개의 값만 입력해야 합니다.
| 1,* | 해당 속성은 최소 한 개 이상의 값이 필수이며, 여러 개의 값을 입력할 수 있습니다.
| 2,* | 해당 속성은 최소 두 개 이상의 값이 필수이며, 여러 개의 값을 입력할 수 있습니다.
|===

//
*Encoding guidelines (Remark / Example)*

* 본문에서 객체는 span:F[Feature], 속성은 span:A[Attribute], 객체 관계는 span:R[Relation]의 색상으로 으로 표현하였습니다. 
* **Remark**는 S-101 DCEG를 국내 환경에 맞게 조정하면서, 국내에서 사용되지 않는 객체에 대한 설명은 번역하지 않았습니다.
* **Example**는 주요 속성의 입력 예시입니다. 필요하면 작업자의 판단으로 각 속성과 타입에 맞게 입력해야 합니다.
